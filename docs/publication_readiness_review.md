# Publication scope and remaining work

The final project document describes a research prototype and a planned evaluation.
The implementation supplies true DAG readiness, shared resource/radio accounting,
neural inference, private SGD/FedAvg, monitored remote attempts, declared prefix
outputs and conditionally admitted local fallback. It also supplies paired-run,
trace-audit and model-replay tools.

Current implementation checks do not establish universal protection benefit.
Zero and negative effects are valid results. A stage recovery can occur inside a
missed workflow. Model calibration for custom fleets, protected checkpoints and
distribution shifts remains unvalidated. Cause heads are resource proxies, not
established causal attribution. Synthetic prefix output validity is not semantic
vision accuracy; configured utility is not measured task quality.

Timing certificates apply only to their matching assumptions and enforced scope.
The independent reference CPU partition cannot certify the live dynamic EDF/GPU/
network scheduler. Host measurements are observations, not hardware WCET proofs.
Facility travel is illustrative; physical motion, RF/5G coverage and safety are
outside the demonstrated model.

Before broader claims, run seed-separated workload families, all supported
comparators and feature ablations, uncertainty analyses, overhead/network/telemetry
sensitivity, distribution-shift calibration and independent simulator or hardware
cross-validation. Preserve regression cases rather than selecting only successes.

Every empirical metric must cite a versioned run/model/configuration identity,
manifest and raw events. Git ships code and runtime bundles; historical developer
runs and training traces remain in the author's ignored local evidence store.
The LaTeX/PDF alone is not a reproduction bundle for those historical results.
Generate fresh artifacts with the scripts, and attach their raw provenance to any
submitted study. See [research methods](research_methods.md) and [project review](project_review.md).
