# ADR 0005: Package and event namespace migration

## Decision

The Python package is `rts_predictive`, and new canonical events use
`rts_predictive.event/1.0`. Run manifests generated by the publication artifact
pipeline use `rts_predictive.run-manifest/1.0`. Existing artifacts with an older
namespace are not silently interpreted as current evidence.

Canonical event payloads do not duplicate reserved top-level identifiers.
Task identity belongs in `task_id`, and `TASK_READY` payloads include the task
name and criticality needed to reproduce task metrics. A remote result is
committed only after a remote execution completion and result transmission.

## Consequences

The namespace change is intentionally incompatible with old event artifacts.
Researchers must regenerate event streams and manifests before using old
tables or figures. Certificate assumptions remain binding; the package rename
does not grant a runtime safety certificate.
