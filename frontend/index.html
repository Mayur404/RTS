What the default simulation uses
The live workspace and default PredictiveRuntime experiment use a heuristic risk score and static remote estimator. Select the saved GNN policy in the experiment builder to execute its weights. Saved weights are not a calibration certificate or a hardware measurement.


      
METHODS & BOUNDARIES / 04
Read the evidence.
Keep simulated outcomes, model predictions, host measurements, and analysis certificates separate.
◉
Simulated
Produced by the discrete-event model under a named scenario and seed. Deadline outcomes and node resource states belong here.
◇
Predicted
A heuristic or learned estimate used to choose an action. The estimate can be wrong and is not a timing bound.
◷
Measured
Timed on specified hardware with a recorded method. No such latency is asserted by this dashboard without a run record.
▤
Analytical
A response-time analysis result under explicit task and scheduler assumptions. No matching certificate is attached to live runs.
CURRENT LIMITS
Research prototype, bounded claims
The simulator uses floating point execution work, simplified network and resource models, and no hardware-calibrated worst-case execution times. The default policy is heuristic. Saved GNN weights and the federated estimator lack a publication-ready validation bundle.
